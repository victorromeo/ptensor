# MNIST in every pTensor weight storage mode

Generated by `train_all_modes.py`. Network: Conv 3x3x8 → MaxPool → Conv 3x3x16 → MaxPool →
Dense 32 → Dense 10 (26,882 parameters). Float baseline trained 3 epochs, then every mode
fine-tuned 2 epochs with quantisation-aware training from that baseline (float32 too, so all
rows have the same training budget). Accuracy and time are measured by the C++ runner on
pTensor over the full 10,000-image test set, batch 1, one x86-64 core (Release build);
time excludes softmax (prediction is the argmax of the logits).

Float baseline before fine-tuning (Keras): 97.72%.

Decode on the fly keeps the weights compressed in flash and decodes them as operators read
them, so it uses no extra RAM; operators fall back to their reference loops for non-dense
tensors, which is why those columns are ~25x slower than float32 on this host. Decoding once
to RAM at start-up restores the dense fast paths (same speed as float32) at the cost of
107 KB of RAM for these weights. Both give identical predictions.

Per-layer storage:

- **float64**: conv1: float64, conv2: float64, dense: float64, logits: float64
- **float32**: conv1: float32, conv2: float32, dense: float32, logits: float32
- **float16**: conv1: float16, conv2: float16, dense: float16, logits: float16
- **int16**: conv1: int16, conv2: int16, dense: int16, logits: int16
- **int8**: conv1: int8, conv2: int8, dense: int8, logits: int8
- **uint7**: conv1: uint7, conv2: uint7, dense: uint7, logits: uint7
- **uint6**: conv1: uint6, conv2: uint6, dense: uint6, logits: uint6
- **uint5**: conv1: uint5, conv2: uint5, dense: uint5, logits: uint5
- **uint4**: conv1: uint4, conv2: uint4, dense: uint4, logits: uint4
- **uint3**: conv1: uint3, conv2: uint3, dense: uint3, logits: uint3
- **uint2**: conv1: uint2, conv2: uint2, dense: uint2, logits: uint2
- **hough4**: conv1: uint4, conv2: uint4, dense: hough L=16 t=16 stride=32, logits: uint4
- **hough3**: conv1: uint3, conv2: uint3, dense: hough L=16 t=4 stride=32, logits: uint3
- **hough2**: conv1: uint2, conv2: hough L=4 t=4 stride=1, dense: hough L=4 t=4 stride=32, logits: uint2
- **int8-full**: int8 weights + int8 activations
